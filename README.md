# 暑假作业打卡神器

> AI拍照导入暑假作业通知，自动生成任务清单，每日打卡，进度可视化。
> 微信小程序 + 云开发 + 通义千问VL AI识别。

## 功能特性

- **AI拍照导入**：拍一张学校作业通知单照片，AI自动识别并生成结构化任务清单
- **每日打卡**：拍照打卡 + 备注，记录每日完成情况
- **进度可视化**：30天日历热力图 + 各科进度条 + 连续打卡天数
- **多学科管理**：按语文/数学/英语/科学等学科分组管理
- **打卡提醒**：每天晚上8点微信订阅消息提醒（需用户授权）
- **分享解锁**：免费用户3个任务，分享给好友解锁全部功能

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | 微信小程序原生开发（WXML + WXSS + JS）|
| 后端 | 微信云开发（云数据库 + 云函数 + 云存储）|
| AI | 通义千问VL（Qwen-VL-Plus）— 拍照识别 + 结构化输出 |
| 变现 | 分享解锁（后续可接微信支付 9.9元买断）|

## 部署步骤

### 第一步：准备工作（约30分钟）

1. **注册微信小程序**
   - 前往 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序
   - 主体类型选"个体工商户"（需营业执照）或"个人"（功能受限）
   - 完成微信认证（300元/年，个体户需）

2. **开通云开发**
   - 在微信开发者工具中打开项目
   - 点击工具栏"云开发" → 开通 → 创建环境
   - 记录环境ID，填入 `app.js` 和 `utils/config.js`

3. **申请通义千问VL API**
   - 前往 [阿里云百炼平台](https://dashscope.aliyuncs.com/) 注册
   - 开通"通义千问VL"服务
   - 获取API Key，填入 `cloudfunctions/parseTask/index.js` 的 `DASHSCOPE_API_KEY`

4. **准备 tabBar 图标**
   - 在 `images/` 目录下放置以下图标（81x81px PNG）：
     - `home.png` / `home-active.png`
     - `task.png` / `task-active.png`
     - `chart.png` / `chart-active.png`
     - `user.png` / `user-active.png`
   - 未激活态灰色 #999999，激活态蓝色 #4A90D9

### 第二步：部署云函数（约15分钟）

1. 在微信开发者工具中，右键点击 `cloudfunctions/login` → "上传并部署：云端安装依赖"
2. 对 `parseTask`、`checkin`、`getProgress` 重复上述操作
3. 等待4个云函数全部部署成功

### 第三步：创建数据库集合

在云开发控制台 → 数据库中创建以下集合：

| 集合名 | 用途 | 权限设置 |
|--------|------|---------|
| `users` | 用户信息 | 仅创建者可读写 |
| `tasks` | 任务清单 | 仅创建者可读写 |
| `checkins` | 打卡记录 | 仅创建者可读写 |
| `subscriptions` | 订阅消息记录 | 仅创建者可读写 |

### 第四步：配置订阅消息模板（可选）

1. 在小程序后台 → 功能 → 订阅消息 → 添加模板
2. 搜索"打卡提醒"相关模板，添加
3. 将模板ID填入 `utils/config.js` 的 `SUBSCRIBE_TEMPLATES.dailyReminder`

### 第五步：小程序备案

1. 在小程序后台 → 设置 → 基本设置 → ICP备案
2. 填写备案信息（需营业执照/身份证、手机号等）
3. 等待审核（7-20个工作日）
4. 服务类目选择"教育-教育信息服务"（无需办学许可证）

### 第六步：提交审核上线

1. 在微信开发者工具中点击"上传"
2. 在小程序后台提交审核
3. 审核通过后发布

## 配置清单

部署前需要修改以下文件中的配置项：

| 文件 | 配置项 | 说明 |
|------|--------|------|
| `app.js` | `env: 'your-env-id'` | 替换为云开发环境ID |
| `utils/config.js` | `CLOUD_ENV` | 替换为云开发环境ID |
| `utils/config.js` | `QWEN_VL_CONFIG.apiKey` | 替换为阿里云DashScope API Key |
| `cloudfunctions/parseTask/index.js` | `DASHSCOPE_API_KEY` | 替换为阿里云DashScope API Key |
| `utils/config.js` | `SUBSCRIBE_TEMPLATES.dailyReminder` | 替换为订阅消息模板ID |
| `project.config.json` | `appid` | 替换为你的小程序AppID |

## 合规注意事项

1. **不做AI批改**：本产品仅做任务管理和打卡记录，不涉及AI批改作业（教育部禁止）
2. **隐私政策**：需在小程序中配置隐私政策，首次使用弹窗告知
3. **AI内容标识**：AI生成的任务清单标注"AI识别结果，请核对"
4. **未成年人数据**：数据存储在微信云开发（腾讯云境内），满足数据安全要求
5. **服务类目**：选"教育-教育信息服务"，非"教育培训"（后者需办学许可证）
